Build a complete full-stack web application called "ToolboxHub" — 
a multi-tool website where the FIRST tool is "ClipMaster" 
(AI-powered video timestamp extractor). The architecture must 
support adding more tools later (PDF converter, image tools, etc.) 
as separate modules.

=====================================================
PROJECT OVERVIEW
=====================================================
This is a MULTI-TOOL WEBSITE like a Swiss Army knife of online tools.

TOOL 1 — ClipMaster:
Users upload long-form videos (or paste YouTube URLs). The app:
1. Extracts audio from video using FFmpeg
2. Transcribes audio locally using faster-whisper (free, offline)
3. Sends transcript to Qwen 3.6 Plus (free) via OpenRouter API
4. AI identifies all clip-worthy moments with timestamps
5. User sees a dashboard with video player + suggested clips
6. User can preview, edit, approve, and export clips

FUTURE TOOLS (just create placeholder routes/pages for now):
- Tool 2: PDF Converter
- Tool 3: Image Compressor
- Tool 4: Audio Transcriber
- Tool 5: Text Summarizer

=====================================================
DATABASE SCHEMA (SQLAlchemy Models)
=====================================================

Table: projects
- id: Integer, Primary Key, Auto Increment
- title: String(255), NOT NULL
- source_type: String(20) — "upload" or "youtube"
- source_url: String(500), nullable
- file_path: String(500), nullable
- audio_path: String(500), nullable
- duration_seconds: Float, nullable
- status: String(20) — "uploading", "extracting_audio", 
  "transcribing", "analyzing", "completed", "failed"
- error_message: Text, nullable
- created_at: DateTime, default=utcnow
- updated_at: DateTime, default=utcnow, onupdate=utcnow

Table: transcripts
- id: Integer, Primary Key, Auto Increment
- project_id: Integer, ForeignKey("projects.id"), unique
- full_text: Text, NOT NULL
- segments: JSON — array of {start: "HH:MM:SS", end: "HH:MM:SS", text: string}
- language: String(10)
- word_count: Integer
- created_at: DateTime, default=utcnow

Table: clips
- id: Integer, Primary Key, Auto Increment
- project_id: Integer, ForeignKey("projects.id")
- start_time: String(10) — "HH:MM:SS"
- end_time: String(10) — "HH:MM:SS"
- start_seconds: Float
- end_seconds: Float
- title: String(255)
- category: String(50) — "highlight", "funny", "emotional", 
  "key_point", "topic_change", "action_item", "quote"
- confidence: Integer — 0 to 100
- reason: Text
- is_approved: Boolean, default=False
- user_notes: Text, nullable
- created_at: DateTime, default=utcnow

Table: rubrics
- id: Integer, Primary Key, Auto Increment
- name: String(255)
- description: Text, nullable
- rules: JSON — array of rule strings
- is_default: Boolean, default=False
- created_at: DateTime, default=utcnow

Relationships:
- Project has one Transcript (one-to-one)
- Project has many Clips (one-to-many, cascade delete)
- Rubric is standalone (no FK)

  - Returns: { success, data: { project_id, title, status } }

POST   /api/clipmaster/process/{project_id}

    Step 1: Extract audio (FFmpeg → WAV 16kHz mono)
    Step 2: Transcribe (faster-whisper large-v3)
    Step 3: AI Analysis (Qwen 3.6 Plus via OpenRouter)
    Step 4: Save clips to DB
  - Each step updates project status + sends WebSocket progress
  - Returns: { success, message: "Processing started" }

GET    /api/clipmaster/project/{project_id}/status
  - Returns: { status, progress_percent, current_step, message }

SERVICE IMPLEMENTATIONS (DETAILED CODE LOGIC)

### 1. video_processor.py
```python
Function: extract_audio(video_path: str, output_dir: str, progress_callback=None) -> str
- Validate video_path exists
- Build FFmpeg command:
  ["ffmpeg", "-i", video_path, "-vn", "-acodec", "pcm_s16le", 
   "-ar", "16000", "-ac", "1", "-y", output_path]
- Run via subprocess.Popen with stdout/stderr capture
- Parse FFmpeg progress output to estimate percentage
- Call progress_callback(percent) periodically
- On success: return audio .wav path
- On failure: raise VideoProcessingError with FFmpeg stderr
- Also: get_video_duration(video_path) -> float seconds
  using ffprobe
```

### 2. youtube_downloader.py
```python
Function: download_video(url: str, output_dir: str, progress_callback=None) -> dict
- Validate URL is a valid YouTube URL (regex check)
- Configure yt-dlp options:
  format: "bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]"
  outtmpl: output_dir + "/original.%(ext)s"
  progress_hooks: [callback function]
- Download using yt_dlp.YoutubeDL
- Extract metadata: title, duration, thumbnail_url
- Return: { file_path, title, duration, thumbnail_url }
- Handle errors: private video, age-restricted, unavailable
```

### 3. transcriber.py
```python
- Module-level: lazy-load WhisperModel (singleton pattern)
  model = None
  def get_model():
      global model
      if model is None:
          model = WhisperModel(settings.WHISPER_MODEL, 
                               device=settings.WHISPER_DEVICE,
                               compute_type=settings.WHISPER_COMPUTE_TYPE)
      return model

Function: transcribe(audio_path: str, language: str = None, 
                     progress_callback=None) -> dict
- Load model via get_model()
- Run: segments, info = model.transcribe(
    audio_path, beam_size=5, word_timestamps=True,
    language=language, vad_filter=True, 
    vad_parameters=dict(min_silence_duration_ms=500)
  )
- Iterate segments:
  - Build full_text with timestamps: "[HH:MM:SS - HH:MM:SS] text\n"
  - Build segments list: [{start: "HH:MM:SS", end: "HH:MM:SS", text: str}]
  - Track progress: (segment.end / info.duration) * 100
  - Call progress_callback(percent) every 5%
- Return: {
    full_text: str,
    segments: list[dict],
    language: info.language,
    duration: info.duration,
    word_count: int
  }
```

### 4. ai_analyzer.py
```python
SYSTEM_PROMPT = """
You are ClipMaster AI — a professional video editor and content strategist.
Your job is to analyze video transcripts and identify ALL moments worth clipping.

RULES:
1. Identify: highlights, funny moments, emotional moments, key points, 
   topic changes, quotable lines, action items
2. Each clip should be 15 seconds to 3 minutes long
3. Prefer natural breakpoints in conversation
4. Assign confidence scores honestly (0-100):
   - 90-100: Must-clip, incredibly strong moment
   - 70-89: Very good clip, recommended
   - 50-69: Decent clip, optional
   - Below 50: Weak, only include if explicitly requested
5. Provide clear 1-2 line reasons for each suggestion
6. Never overlap clips unless absolutely necessary
7. Cover the ENTIRE video — don't skip sections
8. If the video is educational, focus on key takeaways
9. If the video is entertainment, focus on funny/emotional peaks
10. Return ONLY valid JSON — no markdown, no explanations outside JSON
"""

Function: analyze_transcript(transcript: str, rubric_rules: list[str] = None, 
                            progress_callback=None) -> dict
- Build user prompt:
  f"""Analyze this video transcript and find ALL clip-worthy moments.
  
  {"CUSTOM RUBRIC RULES:" + chr(10) + chr(10).join(f"- {r}" for r in rubric_rules) if rubric_rules else ""}
  
  TRANSCRIPT:
  {transcript}
  
  Return a JSON object with this EXACT structure:
  {{
    "clips": [
      {{
        "start_time": "HH:MM:SS",
        "end_time": "HH:MM:SS", 
        "title": "Short descriptive title (max 60 chars)",
        "category": "highlight|funny|emotional|key_point|topic_change|action_item|quote",
        "confidence": 85,
        "reason": "Why this is clip-worthy (1-2 lines)"
      }}
    ],
    "total_clips": 15,
    "video_summary": "Brief 2-3 line video summary"
  }}"""

- For long transcripts (estimated tokens > 100K):
  - Split transcript into 30-minute chunks based on timestamps
  - Add 2-minute overlap between chunks
  - Analyze each chunk separately
  - Merge results: combine all clips, sort by start_time
  - Remove duplicates: if two clips overlap by >80%, keep higher confidence
  - progress_callback after each chunk

- API call via httpx:
  POST {OPENROUTER_BASE_URL}/chat/completions
  Headers: Authorization: Bearer {API_KEY}, Content-Type: application/json
  Body: {
    model: "qwen/qwen3.6-plus:free",
    messages: [{role: "system", content: SYSTEM_PROMPT}, 
               {role: "user", content: user_prompt}],
    temperature: 0.3,
    max_tokens: 16000
  }

- Parse response: extract JSON from content
  - Try json.loads() directly
  - If fails: try extracting JSON from markdown code blocks
  - If fails: regex extract {...} 
  - If fails: raise AnalysisError

- Validate each clip:
  - start_time matches HH:MM:SS format
  - end_time > start_time
  - category is valid enum
  - confidence is 0-100
  - title is not empty

- Retry logic: 3 attempts with exponential backoff (2s, 4s, 8s)
- Return: { clips: list, total_clips: int, video_summary: str }
```
